# 나를 숫자로 표현하기 — 물류 라벨 만들기

경남수학문화관 8~9월 **가족과 함께하는 SW체험교실** — "노동을 줄이고 지혜를 더하는 로봇팔 물류" 프로그램의 **활동 1 웹앱**입니다.

가족이 자기 정보를 입력하면 "나"를 수·그래프로 표현한 **화물 라벨(물류 송장 컨셉)** 카드가 발급되고, 모든 데이터를 담은 **고유 URL**이 자동 생성됩니다. 이 URL을 NFC 태그에 써넣어 피규어와 연결합니다.

## 특징
- **순수 정적앱**: 서버·DB 없음. 모든 데이터는 URL 파라미터에 담깁니다. 예:
  `?n=김민준&b=2015-03-14&h=145&f=7&d=로봇공학자&c=4&l=운동:8~게임:3~책:6`
- URL에 데이터가 있으면(=NFC로 진입) 입력 화면을 건너뛰고 라벨을 바로 렌더링합니다.
- localStorage 등 브라우저 스토리지를 사용하지 않습니다.
- 외부 의존성은 QR 라이브러리(cdnjs) 하나뿐이며, 로드 실패 시에도 URL 복사는 항상 동작합니다.

## 표시 항목
이름의 수(한글 자모 순번 합, 분해 과정 표시) · 태어나서 살아온 날 · 키 · 좋아하는 수(성질 태그) · 나를 이루는 비율(누적 막대그래프) · 나의 색(라벨 강조색).
